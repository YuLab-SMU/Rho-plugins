运行方式和资源边界见 [README](README.md)，后续完整改进流程仍见
[重建设计](../../docs/REBUILD.md#agent-评估与改进插件)。

## 已交付

- Core 的 `evals/claude-code` 七个受控文件迁入本插件 `core-agent/`，包括执行器、
  场景、CLI 控制器、命令入口、评分器回归及说明；原路径不留实现或兼容转发器。
- 显式接收公共 Core 二进制，不假设相邻源码或构建目录。从实际能力取得契约，
  保存二进制／评估源码摘要；Core 自身 Rust 回归与最小库调用示例保留。
- 同一 [入口](run.py) 可调用 Core CLI Agent 消费者、已有 R 产物核验器及普通
  Owner 核验脚本。R 科学规则仍由原核验器拥有。
- 原证据按指定路径离线重评分；新判定单独写文件，不搬动或覆盖原试验材料。
