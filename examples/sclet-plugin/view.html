Read sessions to see what is already running.

Checking packages starts R if needed. Load your data in Notebook first. Reading a ledger runs a small cell; assay matrices stay in R. Missing packages must be installed in the selected R environment.

Plan and execute

Read the current ledger and action registry. Supply its fingerprint and your chosen actions; sclet validates native prerequisites before execution.

Execution updates the selected R object. Execution status and scientific validity are separate; read the report and its evidence checks afterward.

Record an interpretation

An execution record is not an analysis report. Supply the result your analysis supports; sclet audits claims and evidence before recording it.
