# Security policy

Report suspected vulnerabilities privately through the
[Rho project security advisory channel](https://github.com/YuLab-SMU/Rho/security/advisories/new).
Include the affected plugin/source version, platform, impact, reproduction steps
and the least sensitive evidence needed to investigate.

Do not post unpatched vulnerabilities, API keys, signing tokens, personal data,
private project content or unredacted diagnostics in public Issues or discussions.
Maintainers coordinate validation, mitigation and disclosure; no fixed response
or remediation deadline is promised.

This branch contains development source. Fixes target the selected current work;
the archive branch is a historical reference. See [Privacy](PRIVACY.md) and each
consumer README for native execution, model-service and evidence boundaries.
Official signed distribution and installation are separate milestones.
